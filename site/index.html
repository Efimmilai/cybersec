Тренажер кода

Задача: нормализуйте finding для отчета. В браузере Python не выполняется, но вы можете писать решение и сверять с эталоном.

Показать эталонное решение
def normalize_finding(raw_value: str) -> dict:
    value = raw_value.strip().lower()
    return {
        "value": value,
        "valid": bool(value),
        "source": "lab"
    }

Что важнее всего для безопасного учебного инструмента?

Верный ответ: валидация входных данных и явная обработка ошибок. Defensive tooling должен быть предсказуемым и объяснимым.
